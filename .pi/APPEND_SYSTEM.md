# Space Blaster workshop

- The whole game lives in `game.html`, the only source file. Read it before every task.
- Use `game-base.html` as the game base, build on top of it
- The workshop agents (ui-renderer, physics-movement, gameplay-rules, vfx-polish, boss-ai) are defined in `.pi/agents/`. Run them with the `subagent` tool and always pass `agentScope: "project"`.
